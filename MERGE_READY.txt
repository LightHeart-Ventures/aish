🎓 WHAT THIS PR TEACHES

This PR establishes a **sustainable pattern** for adding operator-facing configuration:

1. Infrastructure layer (this PR):
   - Config parsing + loading
   - Sample config with examples
   - Documentation of all knobs

2. Integration layer (Follow-1, 2, 3, ...):
   - Wire each subsystem to read its knobs from config
   - Maintain env var precedence
   - Add tests for precedence logic

3. UX layer (Follow-8, optional):
   - `:config show` command (optional UI)
   - Validation + error messages

By separating infrastructure, integration, and UX, each follow-up PR is:
- Small and focused (15–30 min each)
- Testable independently
- Safe to merge one at a time

This pattern is **reusable** for future configuration layers (profiles, secrets, policies, etc.).
