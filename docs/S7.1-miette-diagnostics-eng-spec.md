# Engineering Spec — TASK-139 / S7.1: miette-backed diagnostics

> Durable repo copy. Source of record: Atum card TASK-139 (`card_8aa65edb8b5a`),
> `engineeringSpec` field. Keep this file and the card in sync.

## Scope
Add a single diagnostic surface (caret + stable code + help) across parse/config/exec errors via **miette + thiserror**, WITHOUT changing routing semantics. The silent route-to-model fallback is preserved byte-for-byte; diagnostics render only at forced-shell (`!`), rc, and exec sites.

## Deliverables
1. **Deps** — `miette = { version="7", features=["fancy"] }`, `thiserror = "2"`. License gate: rows added to `THIRD_PARTY_NOTICES.md`. Confirm `cargo build` AND `cargo build --no-default-features` both pass.
2. **`src/diag.rs`** — one `AishDiagnostic` enum (`#[derive(Error, Diagnostic)]`) with 6 stable codes: `aish::parse::{unbalanced_quote,unsupported_meta,empty_stage,bad_var_ref}`, `aish::config::bad_export`, `aish::exec::not_found`. Each parse/config variant carries `#[source_code] NamedSource<String>` + `#[label] SourceSpan` (except `ExecFailed`). Plus `render`/`render_themed`/`eprint` choosing miette `GraphicalTheme::unicode()` vs `none()` from `style::colors_enabled()`.
3. **`rc::tokenize_diagnosed`** — span-aware sibling of `tokenize_with`; iterate `char_indices()` for byte offsets; every `return None` → typed spanned `Err`. `tokenize`/`tokenize_with`/`tokenize_pipeline` become `.ok()` shims → ZERO behavior change (AC#2).
4. **`rc::parse_into`** — convert the `eprintln!` skip sites to located `BadConfigLine` (header `~/.aishrc:N`); parsing still continues past a bad line (AC#5). `parse_into_diagnosed(...) -> Vec<AishDiagnostic>` seam so emission is testable.
5. **Exec** — at `repl.rs::dispatch` `resolve_program`→None forced site, render `ExecFailed` with a cheap bounded (Levenshtein ≤2) `$PATH` did-you-mean hint reusing `scan_path_commands`.
6. **Forced-shell surfacing** — in `repl.rs::dispatch` and `script.rs`, the `force` branch calls `tokenize_diagnosed` and renders; `Err(_) => NotACommand` keeps the auto path silent. This is the card AC producer.

## Integration points (file:site)
- `src/rc.rs` — tokenize_with / expand_dollar / split_pipeline / parse_into
- `src/repl.rs` — forced dispatch tokenize site, resolve_program None arm, scan_path_commands
- `src/script.rs` — forced dispatch tokenize site
- `src/style.rs` — colors_enabled (theme switch)
- `src/main.rs` — `mod diag;`

## Tests (map to PRD §5 AC 1–6)
1. forced parse failure renders caret + `aish::parse::` code + `help:` (theme none) — diag.rs
2. `tokenize(x) == tokenize_diagnosed(x).ok()` over corpus; existing rc tests untouched — rc.rs
3. all six codes present in render output — diag.rs
4. span offset == offending char index (`|` in `a | | b`, `'` unbalanced, `B` in `export A=1 B=2`), incl. a multibyte case — rc.rs
5. malformed rc line → `BadConfigLine` emitted AND good lines still parse — rc.rs (via `_diagnosed` seam)
6. NO_COLOR → no `\x1b[` but caret+code+help; color → graphical — diag.rs

## Non-goals
No routing-semantics change; no $PATH-wide spell-checker (bounded edit-distance only); no i18n; no anyhow→miette migration; no spanned pipeline tokenizer in v1 (`empty_stage` code defined + unit-tested, producer deferred).

## DoD
6 codes shipped; AC#1–6 covered; `cargo test` + `cargo test --no-default-features` green; CHANGELOG entry; THIRD_PARTY_NOTICES updated.
